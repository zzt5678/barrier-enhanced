# Trash symbol

Unmodified `user-trash-symbolic.svg` from the installed Adwaita icon theme,
`/usr/share/icons/Adwaita/scalable/places/user-trash-symbolic.svg`.
Artwork: GNOME Project, https://www.gnome.org/.
Source: https://download.gnome.org/sources/adwaita-icon-theme/.
License: CC-BY-SA-3.0 or LGPL-3; full attribution and license are in COPYRIGHT.

The bundled 96 px transparent PNG was rendered with ImageMagick:
`convert -background none trash.svg -resize 96x96 trash.png`.
Qt uses the PNG so platform packages do not need an SVG image plugin.
