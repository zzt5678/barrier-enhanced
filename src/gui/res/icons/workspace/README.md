# Workspace navigation icons

Source: GNOME Project, Adwaita icon theme installed on the build host.
Upstream: https://www.gnome.org/ and
https://download.gnome.org/sources/adwaita-icon-theme/

The unmodified source SVG files are retained beside 64px PNG exports. PNGs
avoid adding an SVG plugin requirement to the Windows and macOS packages.

- devices: `devices/computer-symbolic.svg`
- transfers: `status/network-transmit-receive-symbolic.svg`
- settings: `emblems/emblem-system-symbolic.svg`
- folder: `actions/document-open-symbolic.svg`

Artwork attribution: GNOME Project. These assets are provided under the
upstream CC-BY-SA-3.0 or LGPL-3 terms; see the bundled `COPYRIGHT` file.

The separate Weave application mark and device illustration were generated
for this redesign from the user-selected visual concept; they are not GNOME
assets.
